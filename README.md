# Button Clicker Simulator

A simple browser-based clicker you can run from GitHub Pages.

Deployed from the main branch (root). After you push changes to main the workflow will publish the site.

Live site (once the first workflow runs): https://FlexBloxTikTok.github.io/button-clicker-simulator/

To run locally:

1. Clone:
   git clone https://github.com/FlexBloxTikTok/button-clicker-simulator.git
2. Open index.html in your browser.
